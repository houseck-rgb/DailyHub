[시재 - 아침 시재 보고] 앱 패키지 안내
========================================

포함 파일
- index.html          앱 진입 화면
- app.jsx             앱 전체 로직 (직원 화면 / 관리자 화면)
- storage-shim.js      로컬 저장소 어댑터
- manifest.json         홈 화면 설치 설정 (앱 이름, 아이콘, 색상)
- service-worker.js     오프라인 캐싱
- icons/                아이콘 4종 (32/180/192/512)

올리는 방법
1) 이 폴더 전체를 웹 호스팅(예: Netlify, Vercel, 회사 서버, 카페24 등)에
   그대로 업로드합니다. 폴더 구조를 유지해야 합니다.
2) 휴대폰 브라우저로 접속 후
   - iPhone(Safari): 공유 버튼 → "홈 화면에 추가"
   - Android(Chrome): 메뉴 → "홈 화면에 추가" / 자동으로 설치 안내 배너 표시
   를 하면 일반 앱처럼 아이콘이 생기고 실행됩니다.

중요한 제한사항
- 현재 저장 방식은 "이 기기의 이 브라우저" 안에서만 데이터가 남는
  로컬 저장(localStorage) 방식입니다.
- 즉, 지금 이대로는 종로점 직원이 공유해도 관리자 기기에 실시간으로
  뜨지 않습니다. (매장 간 실시간 동기화는 아직 연결 전 상태)
- 실제로 여러 매장·관리자 기기 간 실시간 공유가 되게 하려면
  Firebase Firestore 같은 실시간 데이터베이스 연결이 필요합니다.
  (귀하의 안전관리 앱, 워킹퍼밋 관리 앱과 동일한 방식)
  이 작업은 별도로 요청해 주시면 이어서 연결해 드릴 수 있습니다.

관리자 화면 비밀번호: 12
